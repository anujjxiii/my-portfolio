# Creative Designer Portfolio

A professional, modern portfolio website showcasing branding, illustration, and digital design projects.

## Features
- **Dynamic Filter**: Filter projects by category (Branding, Illustration, Movies, Commercial).
- **Lightbox Gallery**: High-end image viewer with smooth transitions and navigation.
- **Custom Cursor**: Interactive custom cursor experience.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **Performance**: Lightweight and fast-loading using vanilla HTML, CSS, and JS.
